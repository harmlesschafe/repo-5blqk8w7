参数

题图约为 10。拖到 0 就是普通摆动导杆机构，可对比两种情况下极限位置的变化。

(1)导杆的极限位置

B 到导杆的距离恒为 e，所以 B 总在一条与导杆平行、相距 e 的直线上。导杆摆到极限时，这条线与曲柄圆相切，此时 AB ⊥ 导杆。导杆本身切于以 A 为圆心、半径 r+e 与 r−e 的两个圆，而不是切于曲柄圆。打开「作图辅助线」可以看到。

(2)极位夹角 θ

两个极限位置上 AB 都垂直于导杆，所以曲柄两位置之间的夹角与导杆摆角相同：θ = ψ。按题图比例约为 57.7°，K = (180° + θ)/(180° − θ) ≈ 1.94。曲柄转过 180° − θ 时导杆向右摆（快行程），转过 180° + θ 时向左摆回。

(3)传动角 γ

不计摩擦时，滑块对导杆的作用力 F 垂直于导杆，作用线过滑块中心 P；P 在过 C 的导杆线上，其速度 vP 也垂直于导杆。F 与 vP 同向，压力角为 0，所以 γ = 90°，与机构位置无关。
