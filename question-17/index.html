只有 40 − e < lAB < 40 + e 时曲柄转不了整周，而且转不进的只是 AC 方向附近的一个窄扇形（红色），曲柄转三百多度后会倒回来。e 越大扇形越宽。

这题怎么解

(1)图示位置的传动角 γ

不计摩擦，滑块对导杆的作用力 F 垂直于导杆，作用在 B 点。导杆上与 B 重合的点 B4 绕 C 转动，速度 vB4 ⊥ CB。F 与 vB4 的夹角就是压力角 α，它等于直角三角形 CDB 中的 ∠CBD。

sin α = e / lCB　⇒　γ = 90° − α = ∠BCD

按图量得 lCB ≈ 30.2（取 lAC = 40），α ≈ 7.6°，γ ≈ 82.4°。在图上标 γ：可以标在 C 点（CD 与 CB 的夹角），也可以标在 B 点（vB4 与导杆的夹角），两者相等。

(2)最小传动角 γmin 及其位置

cos γ = e / lCB，e 不变，lCB 越短 γ 越小。B 在以 A 为圆心的曲柄圆上，离 C 最近时 lCB = lAC − lAB，此时曲柄 AB 与机架 AC 重叠共线，B 落在 AC 上。

γmin = arccos[ e / (lAC − lAB) ]

按图比例 γmin ≈ arccos(4/20) ≈ 78.5°。点「γmin 位置」可以看到这一位置。

(3)e = 0 时成为转动导杆机构的条件

e = 0 时导杆通过 C。导杆要整周转动，C 必须落在曲柄圆里面，B 才能绕 C 转一整圈，所以

lAB > lAC

反过来 lAB < lAC 时导杆只能摆动。推广到 e > 0，转动导杆需要 lAB > lAC + e；摆动导杆要曲柄能整周转动，需要 lAB < lAC − e。

(4)e = 0 与 e > 0 哪个传力好

e = 0 时 CB 就在导杆上，vB4 ⊥ 导杆，与 F 方向一致，α = 0，γ 恒为 90°。e > 0 时 cos γ = e/lCB > 0，γ 总小于 90°，而且 e 越大 γmin 越小。

所以 lAB、lAC 一定时，e = 0 的传力效果更好。
