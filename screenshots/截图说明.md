# 截图说明

## wokwi/
电路部分由 Wokwi 官方元件库（@wokwi/elements）按 `esp32_mqtt/diagram.json` 渲染；串口日志与 LED 颜色来自 wokwi-cli v0.29.1 的实际仿真（ESP32 经 Wokwi-GUEST 连接 broker.emqx.io:1883）。

| 文件 | 内容 |
| --- | --- |
| 01_wiring.png | 接线图 |
| 02_startup_serial.png | 启动日志：WiFi、MQTT connected、status online、订阅 rgb/set、首次 Publish |
| 03_pot_low.png / 04_pot_mid.png / 05_pot_high.png | 电位器低/中/高位的 JSON 上报 |
| 06_led_red.png / 07_led_green.png | MQTTX 发布 RED / GREEN 后 LED 状态与串口日志 |
| serial_logs/run1_*.txt | 第 1 次仿真完整串口日志（启动 + 电位器三组数据） |
| serial_logs/run2_*.txt | 第 2 次仿真：RED、GREEN 命令 |
| serial_logs/run3_*.txt | 第 3 次仿真：MQTTX 被挤下线期间无命令到达 |
| serial_logs/wokwi_cli_framebuffer_*.png | wokwi-cli take-screenshot 截取的 rgb1 原始像素（初始熄灭 / 红 / 绿） |
